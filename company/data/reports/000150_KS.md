## 三、为什么Doosan是稀缺的"AI双引擎"标的

### 引擎1:Nvidia AI生态系统的核心CCL供应商

**这是Doosan投资逻辑的真正核心**,但被市场认知严重低估。

#### 1.1 Doosan在Nvidia的份额(根据Macquarie研报披露)

- **Nvidia Blackwell compute tray CCL:近乎100%独占供应商**(Macquarie原文:"holds nearly 100% of vendor share in Nvidia's Blackwell compute tray CCL")
- **预计在Rubin compute tray继续保持垄断地位**(基于其CTE指标领先优势)
- **2024年11月起进入Blackwell供应链**,CCL业务2024年/2025YTD营收同比+34%/+97%

#### 1.2 Doosan为什么能独占——不是Df,是CTE

**这是产业研究里最容易被忽视的关键技术细节**:

传统认知关注Df(信号损耗),但**AI compute tray的真正瓶颈是CTE(Coefficient of Thermal Expansion,热膨胀系数)**。原因:
- Compute tray要承载40+颗芯片(GPU+HBM+CPU+LPDDR)
- Rubin GPU的TDP接近2000W(vs Switch ASIC仅~500W)
- CCL受热膨胀会导致PCB翘曲(warpage),直接影响硬件稳定性

**头部厂商M9级CCL的CTE对比**(数值越低越好,a1=Tg以下,a2=Tg以上):

| 厂商 | 产品 | a1 (ppm/°C) | a2 (ppm/°C) |
|------|------|-------------|-------------|
| **Doosan** | DS-7409DYQ | **25** ✅ 行业最佳 | **150** |
| EMC | EM-896K3 | 35-40 | 130-150 |
| TUC | Thunderclad 5Q | 40 | 150 |
| Panasonic | Megtron 9 | 50 | 270 |
| Shengyi | Synamic 6N | 50 | 210 |

**Doosan的CTE指标是同行的1/2-1/3**——这是50年CCL经验 + memory substrate技术积累的"recipe优势",极难被复制。

#### 1.3 Doosan产品线 — CCL全能王

**Doosan的CCL产品在所有应用领域都有布局**:

| 产品系列 | 应用 | 客户 | 2025 1H营收占比 |
|---------|------|------|----------------|
| **DS-7409DY/DQ/DV** | Network CCL(AI server compute tray + switch) | Nvidia, switch OEMs(Arista等) | **55%** |
| **DS-7409HG** | Package CCL(memory module + FCBGA) | **Samsung、SK Hynix** (70-80%份额!) | 15% |
| **DSflex** | FCCL柔性CCL | 小米、华为等 | 11% |
| 其他低端 | 普通PCB、汽车等 | — | 19% |

**关键洞察**:
- Doosan在**Samsung和SK Hynix的memory substrate CCL份额70-80%**——这是另一个被忽视的垄断地位
- 这意味着Doosan既受益AI server主板(Nvidia),又受益HBM/memory super cycle(Samsung/SK Hynix)

### 引擎2:核电/AI数据中心电力(通过Doosan Enerbility)

虽然这部分不直接体现在母公司报表里,但通过30.4%持股Enerbility,Doosan深度受益:

- **与Amazon/X-energy/KHNP战略合作**:动员$500亿投资,2039年前部署5GW SMR用于AWS数据中心
- **Xe-100 SMR制造**:与X-energy签订16个反应堆约束性预订协议,韩国昌原新建SMR制造工厂
- **Fermi America AI Campus**:为德州11GW世界最大AI数据中心提供电力解决方案
- **380MW燃气轮机**:全球第5家、韩国唯一,已签美国一家顶级云服务商5台机组协议

**Enerbility权益价值**:Macquarie按目标价Won120,000估算,Doosan持股价值Won 23.4万亿(超过Doosan当前总市值)。

## 七、我对当前股价的判断 — 修正后的观点

### 之前的判断(基于公开信息)
"过去2年涨30倍,大部分预期已透支,不建议追入"

### 修正后的判断(基于Macquarie研报)

**当前KRW 1,541,000的位置评估**:

**估值层面**:
- 当前对应 2027E PE 27x(基于Won57,073 EPS)
- Macquarie给的合理倍数是 24x(相对保守)
- EMC、TUC的forward PE约27-29x
- **当前估值不算便宜,但也不是泡沫——处于"合理偏高"区间**

**业绩兑现层面**:
- 2026E营业利润+64%,2027E +45%,2028E +40%
- 这种增速完全支撑当前PE
- **如果2026 1H财报(预计4-5月发布)继续超预期,股价向上空间打开**

**风险/收益评估**:
- Macquarie目标价 KRW 2,300,000 → 上行空间 +49%
- 下行风险:如果AI叙事突然破裂,可能跌30-40%(类似2025年11月-2026年1月的回调)
- **风险/收益比约 1:1.2,不算特别有吸引力,但合理**

### 我现在的具体建议

**对于完全没仓位的投资者**:
- **可以考虑3-5%仓位建仓**(我之前说"不建议追入",这个判断需要修正)
- 但**不建议一次建满**,留弹药给可能的回调
- 理想buy zone:KRW 1,400,000以下(对应forward PE ~25x)

**对于已有仓位且涨幅可观的投资者**:
- **不必急于全部获利了结**(我之前的建议过于保守)
- 可以**保留一半仓位继续持有**,享受2027-2028业绩兑现
- 卖一半锁定利润是合理的(因为Volatility Very High)

**对于想要纯CCL弹性的投资者**:
- **EMC仍然是更好的选择**(纯弹性,无控股折价)
- EMC 2026E EPS增速+111%,2027E +84%——比Doosan更陡峭
- Doosan的优势是"双引擎"(CCL + 核电),不是单一CCL弹性

**理想的CCL组合配置**:
- Doosan(韩国双引擎):3-4%
- EMC(台湾纯弹性):3-4%
- TUC(M9率先认证):2-3%
- 合计10%左右AI CCL暴露

### 我修正观点的核心理由

1. **Doosan在Nvidia compute tray的近乎独占地位是垄断,不是竞争市场份额**——这种地位的稀缺性远超我之前的认知
2. **过去2年30倍涨幅,主要是EPS兑现而非估值扩张**——CCL EPS从Won99bn增长到2027E的Won1,184bn是**12倍**,所以30倍涨幅里有12倍是EPS,2.5倍是估值扩张
3. **2026-2028年仍是Doosan CCL业务的爆发期**——不是顶点,是中段
4. **Rubin Orchid module的TAM增量被市场低估**——Macquarie 4月才把这个因素纳入模型
5. **Korea Discount改革 + Treasury share cancellation是隐性alpha来源**——折价缩窄过程才刚开始

**但这个观点的修正不是180度反转**——风险仍然真实存在(波动率、Siltron不确定性、AI整体回调)。所以是"从不建议追入"修正到"在合理风险预算内可以参与"。

## 九、SK Siltron收购的深度分析

这是Doosan未来12个月最大的不确定性,值得专门讨论。

### 交易背景
- 2025年12月:SK Group选定Doosan作为SK Siltron(全球第5大硅晶圆厂)优先收购方
- 收购股权:71%(51%普通股 + 20% Total Return Swap)
- Siltron 2024年营收Won1.7tr,EBITDA率约30-40%

### Macquarie的判断(略偏正面)

**支持的论据**:
- Siltron是全球Top5硅晶圆厂,垄断格局稳定(top 5占90%份额)
- 即使在2023年半导体寒冬也保持正净利
- AI memory super cycle会持续到2026E以后,wafer需求强劲
- Macquarie预测Siltron为Doosan贡献Won 2tr持股价值

**反对的论据(opportunity cost)**:
- CCL扩产ROIC约是Siltron的3倍
- 用Won2tr建CCL greenfield比收购Siltron更赚钱
- 投资者担心管理层资金分配能力

### 资金来源拆解

| 项目 | 金额 (Won bn) |
|------|--------------|
| **现金来源** | **2,183** |
| 母公司现金余额(3Q25) | 1,235 |
| Doosan Robotics减持(68%→50%) | 948 |
| **预估收购成本** | **1,911** |
| Siltron估值(假设上沿) | 5,000 |
| 减:净负债 | 2,294 |
| 70.6%股权 × 净资产 | 1,911 |
| **剩余现金** | **272** |

**关键风险**:剩余现金仅Won272bn,如果Siltron估值偏高,可能需要额外发债。如果发债成本高,会影响整体财务结构。

### Doosan如何处理这个风险

观察:Doosan 4月研报披露,**Siltron acquisition timeline已经被推迟**(原定3月前完成)。Macquarie判断:
- Siltron同业(Sumco、Siltronic、GlobalWafers)YTD股价分别+56%、+51%、+43%——**这给Siltron估值上调了压力**
- Doosan在与SK谈判,争取更合理的价格
- Siltron稳定的EBITDA + Doosan CCL业务的现金流,足以支持收购

### 我的判断

**SK Siltron是中性偏正面的事件**:
- 长期看,增加半导体exposure符合Doosan战略
- 短期看,需要关注最终收购价格——超过Won5tr会引发负面reaction
- 即使最差情况,Doosan的CCL业务现金流足以支撑

**对投资决策的影响**:
- 如果你是短期(<6个月)投资者:**等Siltron价格明朗后再买**
- 如果你是中期(1-2年)投资者:**Siltron不应成为不投资的理由**——长期价值无损
- 如果你是长期(3年+)投资者:**Siltron反而是利好**,增加业务多元化和稳定性
