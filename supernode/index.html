SuperNode Hub · 超节点产业链地图

从“一张 AI 卡”到“一台逻辑上的超级计算机”：用同一张图理解 Compute、Memory、Scale-up、Scale-out、光互联、PCB/CCL、电源液冷和软件，并区分国产算力链、NVIDIA 生态与开放算力生态。

面向初学者面向股票研究中外双链对照v0.1 · 2026-08
先记住一句话：超节点不是“很多 GPU 放在一起”，而是让几十、几百甚至几千颗 AI 加速器通过高速互联，尽可能像一台计算机协同工作。真正的竞争单位正在从“单卡性能”转向“计算 + 内存 + 互联 + 网络 + 光 + 电 + 冷却 + 软件”的系统效率。
投资研究的关键：卡数变多并不意味着所有环节只按卡数同比例增长。随着 Scale-up 域扩大、跨柜连接增加和网络层级加深，交换、光互联、电源与液冷的单卡价值量可能发生结构性变化。

01 · 三条算力路线

先看“整台机器”怎么设计，再进入零部件。

NVIDIA · Proprietary Scale-up

NVLink / NVSwitch 生态

强 GPU + 强专有 Scale-up + CUDA 软件栈；从单机架 NVL72 向跨机架 NVL576 扩大。
72 → 576 GPUGB200 NVL72 → Rubin Ultra NVL576
  • NVL72：72 GPU NVLink 域
  • NVL576：8 个 72-GPU rack，单一 576-GPU NVLink domain
  • 跨 rack 开始同时使用铜与 direct optical connection
S1 官方 GB200 NVL72 · Rubin Ultra NVL576
AMD / UALink · Open Scale-up

开放 Rack-scale 生态

用开放标准连接 GPU、交换和网络，降低对单一专有互联的依赖。
72 GPU / rackAMD Helios + UALink / UALoE
  • Helios：72× MI455X
  • 公开规格：约 1.4 EF FP8 / 2.9 EF FP4
  • UALink 1.0 规范支持最多 1,024 accelerators
S1 官方 AMD Helios · UALink
China · Large Scale-up Domain

国产超节点生态

在单芯片受约束的背景下，更强调通过大 Scale-up 域、互联与系统工程提升整机有效算力。
384 → 8,192 NPU已公开产品与后续路线并存
  • 华为 Atlas 950 SuperPoD：UnifiedBus
  • 64 NPU / 柜，最多 8,192 NPU
  • 业内还存在 384 / 640 / 1,024 等多种方案，需逐厂商验证
S1 官方 Huawei Atlas 950　S2 调研 384/640/1024 为产业调研口径，不视作统一标准产品名。

03 · 八层产业链

点击展开。每层同时回答“是什么、为什么重要、看什么股票变量”。

🧠
STEP 0
AI 芯片 · Compute
GPU / NPU / ASIC：算力从哪里来
›
单卡峰值只是起点。必须同时看精度口径（BF16 / FP8 / FP4）、HBM、互联带宽、功耗和真实模型利用率。
海外NVIDIA、AMD，以及云厂商 ASIC国产昇腾及其他国产 GPU/NPU 路线投资变量出货量、ASP、先进封装/HBM 配套、软件生态迁移
不要脱离精度比较“几 P”峰值 ≠ 有效算力
🧊
STEP 1
HBM + 先进封装 · Memory
算得快之前，先把数据喂得上
›
AI 芯片需要高带宽内存与高密度封装。HBM 容量和带宽决定大模型能否高效驻留和交换数据。
核心环节HBM、Interposer、CoWoS 类先进封装、ABF 载板投资变量HBM GB/GPU、堆叠层数、封装产能、良率、载板面积关联专题可与 Semi Hub 的 CCL / IC 载板 / CoWoS 页面联动
🔗
STEP 2 · 核心
Scale-up · 超节点内部互联
把很多卡尽可能变成“一台计算机”
›
这是理解超节点的灵魂：通信越快，GPU 等待越少。NVIDIA 使用 NVLink/NVSwitch；开放生态推动 UALink；华为 Atlas 950 使用 UnifiedBus。
关注每卡双向带宽、交换层数、all-to-all / all-reduce 效率、域规模产业链交换 ASIC、Retimer、连接器、铜缆、AEC、光互联升级方向从 rack 内铜连接向跨 rack 光连接深入
S1 NVIDIA NVL576 已公开描述采用 copper + direct optical connections；华为 Atlas 950 公开 UnifiedBus + unified memory addressing。
🌐
STEP 3
Scale-out · 集群网络
把很多“超节点”继续连成更大的 AI 工厂
›
Scale-up 解决节点内部，Scale-out 解决节点之间。常见技术包括 InfiniBand、Ethernet、RoCE、UEC 等。规模越大，Spine/Leaf/多层 Clos 结构越复杂。
海外Quantum InfiniBand、Spectrum-X Ethernet、UEC Ethernet国产RoCE Ethernet 与国产交换网络持续优化投资变量端口速率、交换容量、网络层级、NIC/DPU 数量
🔀
STEP 4
交换芯片 + 交换机
“卡越多”为什么可能带来非线性网络价值量
›
交换芯片决定数据如何在大量端口间转发。超节点扩大后，不只 GPU 数量增加，交换层级、端口数和网络冗余也可能增加。
分两类Scale-up switch 与 Scale-out switch关注51.2T / 102.4T / 204.8T 等交换容量代际、SerDes、端口速率投资变量交换芯片单价、每柜数量、交换柜/计算柜比例
💡
STEP 5 · 弹性重点
铜 → AEC → 光模块 → CPO
距离越长、带宽越高，光越重要
›
柜内短距离优先铜，因为便宜、低功耗、低延迟；跨柜以后距离和端口密度上升，光互联的重要性快速提升。
链条DSP / EML / CW Laser / SiPh → TOSA/ROSA → 光模块 → CPO / Optical I/O研究变量每 GPU 光口数、800G→1.6T→3.2T、光模块 ASP、AEC 替代边界最重要不要只算“卡数 × 固定配比”，必须结合拓扑和链路数量
Scale-up 光化1.6TCPO / Optical I/O
🧱
STEP 6
PCB / CCL / 背板 / 连接器
高速信号真正经过的“道路和地基”
›
服务器主板、交换板、背板与高速连接器都需要更高频高速材料。随着 SerDes 速率和端口密度升级，损耗控制、层数、材料等级和加工难度同步提升。
关注高速 CCL 等级、PCB 层数/面积、交换机板价值量、连接器速率专题进入现有 CCL / PCB 产业链地图 →
⚡
STEP 7
电源 + 液冷 · Power & Cooling
AI 计算最终受制于“多少电、怎么散热”
›
Rack 功耗持续上升后，供电和散热从配套件变成系统约束。液冷、CDU、冷板、泵、快速接头、Busbar、Power Shelf、HVDC 等价值量提升。
关注kW/rack、MW/集群、液冷渗透率、PUE、供电效率投资变量每 MW 设备价值量，而不仅是“每台服务器”价值量
🧩
STEP 8
软件栈 · Software
决定 1000P 峰值最后能用出多少
›
通信库、算子、编译器、调度、容错与模型优化直接影响 MFU、吞吐、故障恢复和 cost/token。
NVIDIACUDA / NCCL / TensorRT 等AMDROCm / RCCL 等国产CANN / HCCL 等生态最终指标训练时长、tokens/s、tokens/W、cost per token、goodput

04 · 代际变化：哪里可能出现“单卡价值量”上升？

以下是研究框架，不是未经验证的定量预测。

72 卡：Rack-scale 成为标准计算单元

代表：GB200/GB300 NVL72、AMD Helios 72。重点是把一个 rack 内的计算、内存、交换、电源和液冷做成共同设计。

Scale-up核心价值层
铜连接rack 内仍重要
液冷高密度标配化
光Scale-out 为主

384 级：从单 rack 走向多柜协同

计算柜与交换柜并存，跨柜链路明显增加。国内已出现多个 384 级方案，但不同厂商拓扑不可混为一个标准。

光互联 ↑跨柜连接增加
交换 ↑多柜拓扑
铜柜内仍有优势
电/冷 ↑系统级设计

1,024 级：网络层级与端口密度进一步上升

UALink 1.0 的开放规范明确支持最多 1,024 accelerators。国产 1024 级方案也在产业调研中频繁出现，但具体 BOM 与效率需逐家验证。

光互联 ↑↑跨柜链路更密
交换 ↑↑更多层级/端口
可靠性故障域变大
软件调度难度提升

8,192 级：Scale-up 进入“超级计算机”级系统工程

华为 Atlas 950 SuperPoD 官方口径可扩展到 8,192 NPU。此时关注点从“服务器 BOM”转向“机柜、网络、电力、冷却、可靠性与软件”的整体成本。

光 ↑↑↑跨 rack / 长距离
交换 ↑↑↑大规模互联
电/冷 ↑↑↑MW 级基础设施
评价指标goodput / token/$

05 · 研究方法：不要把“公开公司”和“算力链归属”混为一谈

公司标签含义需要验证什么
海外/NVIDIA 链收入或订单主要受海外 AI Capex / NVIDIA 系统拉动客户结构、产品代际、份额、ASP
国产算力链直接进入国产 AI 芯片、超节点或数据中心供应体系认证、量产节奏、国产替代率、单机价值量
双链/开放链产品可同时服务多种架构，或受益于 UALink/UEC 等开放标准跨平台兼容性、客户集中度、毛利率

下一步公司页建议增加“算力链身份证”：产业环节、海外链暴露、国产链暴露、超节点弹性、核心升级逻辑、主要风险、证据等级。

06 · 黑话速查

P / PFLOPS每秒 10¹⁵ 次浮点运算。比较前必须先确认 FP8 / FP4、dense / sparse 等口径。
Scale-up把一组加速器用超高速互联组成更大的共享计算域。
Scale-out把多个节点/超节点继续通过数据中心网络组成大集群。
Spine / Leaf数据中心交换网络的分层 Clos 拓扑，可理解为不同层级的交通枢纽。
RoCE在以太网上承载 RDMA 的技术体系，常用于 AI/HPC 高速网络。
CPOCo-Packaged Optics，把光引擎更靠近交换芯片，降低高速电连接距离。
